개인정보처리방침

김현우(이하 “개발자”)는 「포포의 작은 방 / ポポの小さなお部屋」의 오프라인 버전과 이 지원 사이트에서 정보를 처리하는 방식을 아래와 같이 안내합니다.

1. 게임에서 수집·전송하는 정보

게임을 이용하기 위한 회원가입이나 로그인이 없습니다. 게임에는 광고, 인앱 결제, 개발자가 설치한 분석 도구가 없으며, 게임 진행 정보를 개발자 서버로 전송하지 않습니다. 이 방침은 온라인 연결 설정을 포함하지 않은 오프라인 출시 구성에 적용됩니다.

2. 기기에 저장되는 정보

게임 진행 상황, 친구에게 지어 준 이름, 소리 설정, 저장 시각, 놀이 기록, 정원·요리 상태, 게임 내 추억 사진이 앱의 기기 내 저장 공간에 저장됩니다. 게임의 이어하기와 화면 표시에 사용되며 개발자는 이 저장 데이터에 접근하지 않습니다.

추억 사진은 게임 화면에서 생성합니다. 기기의 카메라, 마이크, 연락처, 위치 정보, 사진 보관함에 대한 접근 권한을 요청하지 않습니다.

3. 보관·삭제·백업

기기 내 데이터는 앱 데이터가 유지되는 동안 보관됩니다. iOS 설정에서 앱과 데이터를 삭제하면 해당 기기의 앱 데이터를 삭제할 수 있습니다. “앱 정리하기”는 데이터를 남길 수 있으므로 데이터 삭제와 다릅니다.

개발자는 기기 데이터를 수집하지 않아 원격 삭제나 복구를 수행할 수 없습니다. 운영체제의 백업 및 진단 정보는 기기와 Apple의 설정·정책에 따라 처리됩니다. 개발자가 제공하는 클라우드 저장이나 기기 이전은 없으며 재설치 후 복구를 보장하지 않습니다.

4. 이메일 문의

문의 메일을 보내면 이메일 주소, 문의 내용, 이용자가 첨부한 자료를 답변과 문제 해결에 사용합니다. 문의는 선택 사항이며 게임 이용을 위한 필수 절차가 아닙니다. 비밀번호, 결제 정보, 불필요한 개인정보는 보내지 마세요.

문의 자료는 응대와 문제 해결에 필요한 기간 동안 보관한 뒤 불필요해지면 삭제합니다. 적용되는 법령상 보관 의무가 있는 경우에는 해당 의무에 따릅니다. 문의 자료의 열람·정정·삭제 등 요청은 아래 이메일로 연락해 주세요.

5. 지원 사이트와 외부 서비스

이 사이트에는 별도의 문의 입력 폼, 광고, 개발자가 설치한 방문 분석 스크립트가 없습니다. 사이트 제공업체는 페이지 전달과 보안 운영을 위해 IP 주소, 브라우저 정보, 접속 기록 등 기술 정보를 처리할 수 있습니다. 이메일 링크를 누르면 이용자의 메일 앱이 열리며 해당 이메일 서비스의 정책이 적용됩니다.

이 사이트는 GitHub Pages를 통해 제공됩니다. 서비스 제공업체의 정보 처리는 GitHub 개인정보 처리방침을 참고해 주세요.

6. 아동의 정보

나이에 관계없이 게임을 플레이하기 위해 개인정보 제출을 요구하지 않습니다. 이메일 문의 시에도 불필요한 아동 개인정보를 보내지 마세요. 문의 정보 삭제를 원하면 보호자가 아래 연락처로 요청할 수 있습니다.

7. 변경 및 연락처

기능이나 정보 처리 방식이 바뀌면 이 페이지와 수정일을 갱신합니다. 온라인 기능을 제공하게 되면 실제 서비스 시작 전에 관련 안내를 업데이트합니다.
